  QUICK START  (3 easy steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. INSTALL DEPENDENCIES
     Double-click:  Install_Never_Suite.bat
     (Requires Python 3.10+  —  get it free at https://python.org)

  2. LAUNCH NEVER HUB (Control Center)
     Double-click:  Start_Never_Hub.bat
     Never Hub is your command center — toggle all modules from one place.

  3. ENJOY
     Use the Hub's ON/OFF switches to enable the modules you want.
     Never Hub minimizes to the system tray.

  Q: "python is not recognized" error?
  A: Install Python from https://python.org — check "Add Python to PATH"
     during installation, then re-run Install_Never_Suite.bat.

  Q: Module won't start?
  A: Run Install_Never_Suite.bat first to ensure all packages are installed.

  Q: Never Drop QR code doesn't work?
  A: Make sure both devices are on the same Wi-Fi network.
